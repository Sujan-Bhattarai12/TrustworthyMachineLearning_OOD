# Official CIFAR-10-C protocol

The final study uses official pre-generated CIFAR-10-C arrays. No synthetic filters are regenerated by our code for final benchmark measurements. CIFAR-10-C itself consists of **algorithmically generated corruptions**, not a natural-shift dataset; “official” does not mean “non-synthetic.”

The current complete definition is [FINAL_STUDY.md](FINAL_STUDY.md). Main root: results/expanded_cifar10c_5000dev_2000test/. Precursor setup records only: results/final_cifar10c/. Development corruptions are Gaussian noise and brightness; primary test is Gaussian blur. Severity0 uses the clean image,1–5 use official blocks. The local loader validates labels/shapes and protocols lock file SHA256 values. The original downloaded archive MD5 was not independently verified.

The additional ResNet-50 panel uses official shot noise, motion blur, fog and JPEG compression without detector refitting; same 187 retained images. Older custom-corruption studies remain archived and must not be presented as CIFAR-10-C benchmark results. Additional official corruption types broaden empirical scope without establishing universal OOD generalization.
