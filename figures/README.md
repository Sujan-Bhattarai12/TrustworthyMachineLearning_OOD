# Figures for the final project

## Official same-image examples

[official_examples/](official_examples/README.md) shows one shared original CIFAR-10 test image at clean severity 0 and official CIFAR-10-C Gaussian-blur levels 1–5. It includes the saved final IG and Grad-CAM maps for ResNet-50, ViT-B/16 and Swin-T. No custom corruptions are generated.

## Aggregate results

The authoritative four performance figures (PNG/PDF), tables and captions are in [results/reporting/final/](../results/reporting/final/README.md). These summarize cohorts rather than one image.

## Historical images

Manually generated corruption illustrations and loose historical examples have been removed. `archive/historical_validation/` retains earlier convergence/stability plots as historical evidence only; these are not final official CIFAR-10-C examples or fresh validation of all final models.
